# Weekend Bingo · 周末小事俱乐部

**[打开网页，开始你的周末小冒险](https://lcheng666888.github.io/weekend-bingo/)**

不知道周末做什么时，抽一张 3 × 3 探索卡。从一件轻松的小事开始，完成就盖章，连线就庆祝。

## 功能

- 30 条原创任务，覆盖室内、户外和低成本活动；每次随机抽取 9 项，卡内不重复。
- 30 枚专属手绘 SVG 图标，与任务固定关联，换卡或刷新不会随机改变。
- 点击盖章，再点取消；横、竖或对角连线时庆祝，并标出所有完成连线。
- 自定义任务支持本地主体与装饰组合、图标预览和重复检查，不依赖在线 AI。
- 任务库支持搜索、来源 / 类别 / 状态筛选，自己的任务可编辑、停用和重新启用。
- 换卡前自动归档，保留任务原稿、图标、盖章、完成时间和连线；编辑不改写历史。
- 自动保存、旧版存档迁移、JSON 备份导入导出。未知创建或完成时间如实标注。
- 支持手机布局、键盘操作和减少动态效果设置。

进度保存在各自浏览器中。更换地址或设备时，可先导出备份，再在新位置导入；没有账号注册或云端进度同步。

## 本地运行

直接打开 `index.html`，或在本目录运行：

```sh
python -m http.server 4173
```

访问 `http://localhost:4173/`。没有构建步骤，也不需要安装前端依赖。全部图形与代码随仓库保存。

## 文件

- `index.html`、`style.css`：手账界面。
- `core.js`、`model.js`、`repository.js`：任务与连线、快照与迁移、浏览器保存。
- `app.js`、`collections.js`、`editor.js`、`backup.js`：卡片、任务库和记录、图标编辑、备份交互。
- `icons.js`、`icons/`：本地图标工具包与独立 SVG，[查看全部图标](https://lcheng666888.github.io/weekend-bingo/icons/gallery.html)。
- `*.test.cjs`：自动测试。
- `USAGE.md`：详细使用说明。

## 验证

使用 Node.js 运行：

```sh
node --test *.test.cjs
```

15 项测试覆盖随机去重、八种连线、图标唯一性、存档迁移、编辑和停用、历史快照、完成时间、备份校验、保存失败回滚与多页面冲突。
